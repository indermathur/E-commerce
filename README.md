# 🛒 E-Commerce Website (React)

A modern and responsive **E-Commerce Web Application** built using **React.js**.
This project includes multiple sections like **Men, Women, Kids**, along with a fully functional **Add to Cart system**.

---

## 🚀 Features

* 👕 Separate sections for **Men, Women, Kids**
* 🛍️ **Add to Cart** functionality
* ➕ Increase / Decrease product quantity
* 💰 Dynamic price calculation
* 🔄 Reusable components
* 📱 Fully responsive design
* ⚡ Fast performance with React

---

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript (ES6+)
* **Styling:** CSS 
* **State Management:** useState / useContext 
* **Routing:** React Router

## ⚙️ Installation & Setup

1. Clone the repository

```bash
Unzipped E-Commerce file 
```

2. Navigate to project folder

```bash
cd your-repo-name
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```
